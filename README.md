# BR Tun — тестовые сборки

Приложение для подключения по собственной VPN-подписке. Этот репозиторий предназначен для готовых файлов и инструкций.

## Скачать

Откройте раздел Releases. Для Windows 10/11 x64 выбирайте `BR-Tun-0.7.2-Setup.exe`. ZIP — дополнительная переносимая версия, требующая полной распаковки. Для Android 7+ — `BR-Tun-0.7.2-Android-test.apk`.

## Установка Windows

1. Скачайте Setup.exe из Releases.
2. Запустите установщик и нажмите «Установить».
3. Откройте BR Tun через созданный ярлык.
4. Добавьте свою ссылку подписки, выберите сервер и подключитесь.

Удаление доступно через список установленных приложений Windows. Переносимую версию нужно полностью распаковать и открыть `BR Tun.exe` из распакованной папки.

## Статус

Это предварительный тестовый выпуск, не стабильный релиз. Windows-установщик пока без подписи издателя, Android APK подписан тестовым ключом. Проверка настоящего Android-туннеля на Redmi Note 12 и установка/удаление на чистом Windows ПК ещё требуются. Версии iOS, macOS, Linux и подтверждённая поддержка телевизоров пока не опубликованы.

Для встроенного магазина требуется настроенный адрес сервиса BroVPN. Пользовательские URL подписок содержат данные доступа: не публикуйте их в Issues.
